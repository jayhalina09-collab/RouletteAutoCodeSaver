# Build APK from Android phone (no PC)

## Method: GitHub Actions

1. Create a GitHub account.
2. Create a new repository.
3. Upload all files from this ZIP.
4. Open repository > Actions.
5. Run the Android APK workflow.
6. Wait for completion.
7. Download the APK artifact.
8. Install the APK on your phone.

If Android blocks installation:
Settings > Allow unknown apps > enable for your browser/files app.

## First run:
- Open app
- Tap START
- Allow required permissions
- Keep battery optimization disabled for the app for 24/7 running.
